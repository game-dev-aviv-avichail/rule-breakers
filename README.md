# Rule Breakers

**Every rule you make, you have to follow too.**

![Rule Breakers concept sketch](images/screen-sketch.svg)

Rule Breakers is a turn-based puzzle game for PC and the browser. You're on a small grid with a few rival characters, and you have to collect every coin and reach the exit. You can't fight the rivals. You can only change the rules of the arena, using cards like *No one may step on red tiles* or *Everyone moves the opposite way*.

The catch: every rule you play applies to everyone, including you. A rule that traps the Chaser might also cut off your own way to the door, so each card is a weapon and an obstacle at the same time.

The idea started from playground games where kids invent the rules and change them halfway through.
